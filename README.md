## 폴더 구조

```
src/
├── assets/         # 이미지 (프로필, 프로젝트 썸네일, 아이콘)
├── components/     # Navbar, Hero, About, Projects, Experience, Contact, Footer 등
├── data/           # projects.js, experiences.js (콘텐츠 데이터)
├── pages/          # Home, ProjectDetail
├── App.jsx
└── main.jsx
```
